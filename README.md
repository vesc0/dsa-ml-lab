# dsa-ml-lab

Course: Machine Learning Algorithms Lab

The goal of the course project is to study and upgrade four core machine learning algorithms implemented in this repo:
- Naive Bayes

**Contents**
1. Project Structure
2. Quick usage example
3. Goals / Suggested Improvements
4. Experiments & Reproducibility

**Project Structure**
- **Files**:
  - [naive_bayes.py](naive_bayes.py): Naive Bayes implementation (initial).
  - [linear_regression.py](linear_regression.py): Linear Regression implementation (initial).
  - [requirements.txt](requirements.txt): Python dependencies.
- **Data**:
  - See the `data/` folder for used CSV datasets.
- **Materials**:
  - See the `materials/` folder for explanations.

**Quick usage example**
- **Setup**:
  - Create and activate a virtual environment, then install dependencies:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

  - Run a script directly (each script contains examples or simple runners):
```bash
python naive_bayes.py
python linear_regression.py
```

  - Adjust or extend scripts to run experiments with different datasets or parameters.
